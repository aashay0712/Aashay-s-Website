# Aashay's Personal Website

A personal website I built for my IT Data Analytics course at Nova Scotia Community College (NSCC). It introduces me, shows my wildlife photography, lists the IT skills I am learning, and gives ways to contact me.

**Live site:** https://aashay0712.github.io/Aashay-s-Website/

## About This Project

I built this site step by step as part of my coursework. Each assignment added something new: a responsive layout, a skills grid, clickable photo thumbnails, and CSS animations. I used only HTML and CSS, with no JavaScript.

## Features

- **Responsive layout:** Flexbox cards that sit side by side on large screens and stack into one column on small screens, using media queries.
- **Skills grid:** A CSS grid with six IT skills (Python, Networking and Security, HTML, Troubleshooting, SQL, Windows Administration). Each has an animated icon drawn with inline SVG and CSS.
- **Wildlife photo gallery:** Small thumbnails that open the full-size photo on its own page.
- **Contact section:** A LinkedIn link, a phone number that appears when clicked, and an email link that opens the user's email app.
- **CSS animations:** A bouncing ball that travels across the page, plus a profile photo that flips on hover.
- **Sunset theme:** A custom colour palette, a hero background photo, and Google Fonts (Playfair Display and Nunito).

## Built With

- HTML5
- CSS3 (flexbox, grid, media queries, keyframe animations)
- Inline SVG
- Google Fonts

## Project Structure

- `index.html`: the home page
- `styles.css`: all of the styling
- `photo1.html` to `photo7.html`: the full-size photo pages
- `thumbs/`: small copies of the photos used as thumbnails

## What I Learned

- Building responsive layouts with flexbox and media queries
- Creating grid layouts with CSS grid
- Making animations without JavaScript
- Organizing a website into several pages and linking them together
